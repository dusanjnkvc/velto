# Velto

Personal finance, savings and invoices for PC and Android.

Open https://dusanjnkvc.github.io/velto/ and sign in with your Dropbox account. Enable `files.content.read` and `files.content.write` for the configured Dropbox app. The public repository contains app code only. Personal financial data stays in your private Dropbox at `/Velto/velto-data.json` (or the corresponding app folder).

First connect from the original PC using Account → Connect & sync, or export its JSON backup and import it after signing in online. Always check the synchronization status before changing device. Revision conflicts preserve both versions and require an explicit choice.

On Android, open the site in Chrome and choose Add to Home screen. Internet access is needed to load and synchronize your data. The login is Dropbox authorization; no personal password verifier or financial records are published here.

Third party payment QR licenses are in vendor/.
